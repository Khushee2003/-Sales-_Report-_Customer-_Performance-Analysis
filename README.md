# Excel_Project2
# Sales Report & Customer Performance Analysis

## Project Overview

This project focuses on analyzing sales performance and customer
contributions using Microsoft Excel.

The analysis helps understand net sales across different customers,
markets, regions, and divisions over multiple years.

An Excel Pivot Table is used to summarize sales data and compare
performance across 2019, 2020, and 2021.

## Objectives

- Analyze customer-wise net sales.
- Compare sales performance across different years.
- Identify sales growth and changes.
- Analyze customer contributions to total sales.
- Understand sales performance across different markets and divisions.
- Create a structured and interactive sales report.
